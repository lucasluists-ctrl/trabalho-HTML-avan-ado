# 🌈 Trabalho HTML - Enciclopédia ROBLOX

Projeto acadêmico desenvolvido com **HTML** com o objetivo de criar uma enciclopédia sobre a história, cultura e jogos marcantes da plataforma Roblox.

---

## 📖  Sobre o projeto

A **Enciclopédia ROBLOX** foi desenvolvida como atividade acadêmica para colocar em prática conceitos de **HTML e estruturação de páginas web**.

O projeto possui mais de 10 páginas HTML conectadas através de menus e links, utilizando tags semânticas, formulários, elementos multimídia e recursos interativos.

O objetivo principal foi criar um site completo utilizando os conteúdos aprendidos durante as aulas.

---

## ☁️ Conteúdo da Enciclopédia

### 📜 História do Roblox

- Criação do Roblox
- Lançamento oficial do Roblox

### ⚠️ Eventos e Incidentes

- Incidente de 1º de abril de 2012

### 🔊 Sons e Cultura

- O famoso som "Oof"

### 🎮 Jogos Marcantes

- Natural Disaster Survival

---

## 🧩 Páginas do site

Além dos artigos da enciclopédia, o projeto possui páginas destinadas a outras funcionalidades:

- 🏠 **Início** — apresentação da enciclopédia e acesso aos artigos.
- 🎨 **Artes** — galeria com artes relacionadas ao Roblox.
- 👥 **Comunidade** — espaço com formulário e interação com o usuário.
- 📖 **Sobre** — informações sobre o projeto.
- 📝 **Cadastro** — página inicial para cadastro do usuário.

---

## 🛠️ Recursos HTML utilizados

Durante o desenvolvimento foram utilizados diversos elementos HTML estudados em aula, incluindo:

- Tags semânticas: `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`
- Imagens com `figure` e `figcaption`
- Áudio com `audio`
- Vídeos com `video`
- Formulários
- `input` de diferentes tipos
- `datalist`
- `details` e `summary`
- Tabelas
- Links para navegação entre páginas
- Elementos de marcação de texto
